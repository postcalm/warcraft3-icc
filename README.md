# Icecrown Citadel

Implementation of Icecrown Citadel on the Warcraft III engine.

## Basic features

- Buff System - similar to WoW; two separate panels are displayed with negative and positive effects
- Combat System - records the level of aggression and checks the combat on a global level
- Third-Person Camera & WASD Movement
- Save System (testing stage)

## Implemented heroes

- Paladin - Protection
- Priest - Holy
